# Polyphase Float 0.12.0 completion status

## Conservative estimate

The project is approximately **58 percent ready for version 1.0**, with about
five percentage points of uncertainty.

The functional numerical surface is farther along than this percentage. The
estimate weights production obligations heavily.

## Major blocks completed through 0.12.0

- complete lowercase reference inventory mapping;
- public open-source release and reproducible packaging;
- strict official-header and compiler validation;
- retained-sample and counterbalanced benchmark evidence;
- automated performance-regression gates;
- evidence-gated machine product profiles;
- beginner and complete function documentation;
- optional OpenMP and verified serial packages;
- parser and PPFIF fuzz harnesses;
- context-allocation failure injection and transactional state preservation;
- thread ownership, thread-exit cleanup, cache lifecycle, and ThreadSanitizer;
- ABI epoch 1 source contract, runtime layout record, ELF symbol governance,
  and old-binary compatibility validation.

## Highest-weight remaining work

1. branch-complete semantic and adversarial test matrix for all public
   functions;
2. broader allocation-failure control, including formatting, packet, and
   selected special-function allocations;
3. sustained fuzzing and permanent corpus governance;
4. native Windows, macOS, ARM64, and additional data-model validation;
5. cross-machine independent correctness and performance replication;
6. completion and review of the principal mathematical certification proofs;
7. performance refinement for logarithms, reciprocal square root, inverse
   angles, hyperbolic functions, and special-function families;
8. final 1.0 SONAME and support-window decision.

## ABI status

ABI epoch 1 is governed on the supported Linux ELF LP64/GMP64 baseline. It
preserves the 0.11.0 interface and establishes automated comparison for future
releases. It is not yet a universal cross-platform ABI freeze.
